═══════════════════════════════════════════
글 작성 원칙 — Google AI 콘텐츠 페널티 회피
═══════════════════════════════════════════

목표는 "AI 검출 우회"가 아니라 **진짜 좋은 글을 쓰는 것**. 다음 원칙을 항상 적용:

**A. 매번 다른 구조 (가장 중요)**
다음 5가지 패턴 중 1개를 랜덤 선택. 같은 패턴을 연속 2회 사용 금지:
  1) 도입 → 개념 → 사례 → 실수 → 정리 (전형)
  2) 충격 사례/장면 → 원리 → 데이터 → 적용 → 마무리 (스토리텔링)
  3) Q&A — 5~7개 질문에 답하는 구조
  4) 비교 분석 — 상황 A vs B 매트릭스 중심
  5) 의사결정 트리 — 프리플랍 → 플랍 → 턴 → 리버 단계별

(직전 1~2개 글의 구조는 `git log --oneline -3 blog/posts/` 와 해당 파일들 첫 50줄 확인 후 다른 패턴 선택.)

**B. 1인칭/구어체 자연 삽입**
- "제 경험상…", "필자가 자주 보는 실수는…", "라이브에서 한 번은…" 같은 표현을 1~2회만 자연스럽게.
- 절대 매 단락마다 넣지 말 것 (오히려 부자연).
- 구체적 핸드 히스토리 1개 (스택/포지션/보드/액션 모두 명시).

**C. 정밀한 수치만**
- "약 80%" 같은 어림수 금지 → "81.95%" 처럼 소수점.
- 포커 확률은 검증된 수치만 사용. 모르면 그 수치 빼고 정성적으로 서술.
- 수치 근거: PokerStove/Equilab/GTOWizard 계산 결과 인용.

**D. 한국어 자연스러움**
- 번역체 금지: "~하는 것이 중요하다" → "~해야 한다" / "~가 핵심이다"
- "결론적으로", "또한", "마지막으로" 남발 금지 (각각 1회 이하)
- 한국 포커판 용어 자연 사용: 콜코, 다이, 올린, 쇼다운, 콜드콜, 스퀴즈, 도네이트 등

**E. 구체적 레퍼런스**
- GTO 솔버(PioSolver, GTOWizard, MonkerSolver) 결과 인용 (가능 시).
- 유명 토너먼트(WSOP, EPT, 트리톤) / 플레이어 이름 자연스럽게 1~2회.
- 이전 블로그 글과 내부 링크 1개: `[관련 글: 제목](/blog/<slug>)` 형식. 
  (`blog/posts/` 디렉토리에서 관련 주제 찾아서 사용. slug는 해당 파일의 frontmatter에서 확인. 무관하면 생략.)

**F. 문장 리듬**
- 짧은 문장(20자 이내) + 긴 문장(60자 이상) 의도적으로 섞기.
- 같은 단어/표현 3문장 연속 금지.
- 모든 단락이 같은 길이면 부자연스러움.

**G. AI 티 나는 표현 절대 금지**
- "이 글에서는 ~를 살펴봅니다"
- "결론적으로 말씀드리면"
- "다음과 같은 점들이 있습니다"
- "효과적으로" / "효율적으로" / "다양한" / "유용한" 의 남발
- 모든 섹션을 "정의 → 예시 → 정리" 똑같이 끝내는 패턴

═══════════════════════════════════════════
형식 사양
═══════════════════════════════════════════

- 한글 1,500~2,200자 (조금 길게 — 깊이 신호)
- 6~10 섹션, `##` `###` 만 사용 (HTML 태그 금지)
- 표 1~2개 (마크다운 `|...|`)
- 인용 박스 1~2개
- 마지막에 `> 💡 **핵심 정리**` 인용 박스 (3~5개 요점)
- 본문에서 "K-POKER", "kpoker.win" 절대 언급 금지

YAML frontmatter (반드시 파일 시작):
```
---
title: "{topic.title}"
slug: "{영문 소문자+숫자+하이픈만, 한글/특수문자 절대 금지, 30자 이내}"
date: "{오늘 YYYY-MM-DD}"
category: "{topic.category}"
excerpt: "(150자 내외 SEO 디스크립션)"
keywords: {topic.keywords JSON 배열}
---
```

**slug는 반드시 ASCII만.** 한글 슬러그는 URL 인코딩 이슈로 Cloudflare에서 404 발생.
예시: "AK vs JJ 코인플립" → `ak-vs-jj-coinflip-myth` (의미 보존하되 영문 변환)
주제 키워드를 영문/포커 용어로 슬러그화. 너무 길면 핵심만 (예: position-power, c-bet-frequency, starting-hand-chart).

═══════════════════════════════════════════
실행
═══════════════════════════════════════════

3. `blog/posts/{YYYY-MM-DD}-{slug}.md` 로 저장.
4. `scripts/topics/queue.json` 에서 사용한 `topics[0]` 제거 후 저장.
5. `npm run build` 실행. 실패 시 원인 분석 후 글 수정 (최대 2회 재시도).
6. **자동 커밋/푸시 (사용자 컨펌 X):**
   - `git add -A blog/ scripts/topics/queue.json public/sitemap.xml`
   - `git commit -m "post: {title}"` (Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com> 포함)
   - `git push origin main`
7. 사용자에게 짧게 보고 (3~5줄):
   - 제목, 게시 URL: https://kpoker.win/blog/{slug}
   - 단어수, 사용한 구조 패턴
   - 빌드/푸시 결과
